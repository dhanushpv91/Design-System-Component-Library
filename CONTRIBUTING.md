# Contributing

1. Use Node.js 20+ and run `npm install`.
2. Branch from `main`; keep changes focused.
3. Edit tokens only in `tokens/design-tokens.json`, then run `npm run tokens:build`.
4. Add or update tests alongside component changes.
5. Before opening a pull request run `npm run verify`.

For UI changes also check keyboard focus, contrast in both themes, responsive behaviour and reduced motion.

Commit style: short imperative messages, e.g. `feat(button): add icon-only size`.
