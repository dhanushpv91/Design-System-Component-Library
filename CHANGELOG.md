# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - Week 1 foundation

### Added

- Design token source with light/dark themes and a generator for CSS variables, typed tokens and a Tailwind preset.
- CSS cascade-layer architecture and base styles.
- `Button`, `Input`, `Badge`, `Card` and `Container` components.
- Vite library build, ESLint, Prettier and Vitest setup.
- WCAG AA contrast tests for token pairs.
